# Project: DevLingo

## Objective
Build an application that helps software developers learn English.

## Development Methodology
Follow Spec-Driven Development (SDD).

## Rules
- Do not implement features without an approved specification.
- Do not select technologies before technical planning.
- Separate specification, planning, tasks, and implementation.
- Do not proceed to the next phase without user approval.
- Ask questions when requirements are unclear.
- Prefer simple, maintainable solutions.
- Do not create files or modify code without explicit authorization, except when specifically requested.

## Language
- Write specifications, plans, and tasks in clear technical English.
- Communicate with the user in Brazilian Portuguese.
- Explain technical decisions in Portuguese.
- Use English for code and identifiers.
